# Birthday wishes website

A small static birthday wishes website built with HTML, CSS, and JavaScript.

## Run locally

Open `index.html` in a browser, or serve this folder with any static web server.

## Deploy on Hostinger

1. In Hostinger hPanel, open **Websites → Manage → File Manager**.
2. Open the `public_html` directory for the domain you want to use.
3. Upload `index.html`, `styles.css`, and `script.js` from this repository.
4. Visit your domain and clear the browser cache if the old page is still showing.

Alternatively, compress the three files into a ZIP, upload it to `public_html`, and extract it there. Make sure `index.html` is directly inside `public_html`, not inside an extra folder.
